# Mission Control

## Purpose
Mission Control is the "Brain" of the research framework. It is where high-level research goals are documented and translated into technical execution plans.

## Workflow
1. **Journaling:** Use the `journal/` folder for daily notes, brainstorms, and observations.
2. **Experiment Definition:** Create a Markdown file in `experiments/` (e.g., `E001_initial_sweep.md`) to define the goals, hypotheses, and intended parameters for a new study.
3. **Blueprint Generation:** Use `u_mission_control` to translate the Markdown goals into a Hydra experiment config in `r_resources/r_configs/experiments/`.
