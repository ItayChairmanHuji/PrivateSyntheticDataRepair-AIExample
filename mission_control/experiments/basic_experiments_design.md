# Basic Experiments Design 

## Goal
Measure the quality and scalability of the weighted repair algorithm compared to the other repair algorithms. 

## Parameters
The experiments should run on the datasets adult, census tax and compas. 
The experiments will use synthetic data generated by the systems aim, mst and patectgan
The experiments will be repeated with 8 random seeds to avoid random errors. 
The models will train in advance and will be exported and saved on the local disk. Datasets could be sampled at any time. 
The random seeds are relevant only to the sampling stage of the synthetic data generation. 
Constant marginals will be calculated in advanced over the private dataset. 
Each marginal will be noised with Gaussian noise with scale 1/private_data_size 
As for now, the full list of marginals is saved under the name 1.0_sampled_100 in the resource folder 
The repair algorithms that should be used are the VC repair algorithms (vanilla, classic and weighted). 


## Sweeping Values
The experiment will sweep over the following
1. epsilon: The privacy budget of the synthetic generation systems. Values can run between 0.1 and 1
2. size: The size of the synthetic data sampled from the synthetic data generation model. Values can run between 100K to 1M. 
3. marginals: The number of marginals used in the synthetic data. It is important to note that the marginals should only be added during the sweep and not replaced (i.e, if in marginals count i we used a set of marginals, in any marginals count great than i, these marginals must be present). Values can run between 10 to 100 


## Measurements
The experiments aim to measure
1. Deletion ratio
2. Marginals loss 
3. Marginal error
4. Runtime
5. ML accuracy (of each of the ML models)
6. 2-way TVD between the private and repaired data. 
MAKE SURE TO DO ALL THE MEASUREMENTS IN EVALUATING ANYWAY TO AVOID RERUNS
## Default Values
When not sweeping, use
1. epsilon = 0.5 
2. size = 500K
3. marginals = 50
