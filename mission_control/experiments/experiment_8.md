# Experiment 8

## Goal
Compare the VC repair algorithms as function of eps. 

## Datasets 
Use adult, census, compas and tax for experiments. 
Use adult100 for canary run. 

## Synthetic data generation 
Create synthetic data with size 300K, generated by models of MST, PATECTGAN and AIM with different eps. 
The models are already located in the models folder, so sample only. 
Use 5 different seeds for the sampling algorithm. 
The sweep is done here, as you choose different models to sample from. 
You can start the sweep from eps=0.1. 

## Marginals generation 
Marginals should be already generated, use file obtainer to load them. 

## Repairing
Use the 3 VC repairing algorithms. 
Make sure that: 
1. **Vanilla VC**: Takes the vertex with the maximal degree at each iteration. 
2. **Classic VC**: Selects an edge randomly and removes both endpoints. 
3. **Weighted VC**: MUST use the dynamic (adaptive) alpha calculator. 
4. **Runtime**: The duration of the repair process MUST be measured and saved into `metadata.json` as `repair_runtime`.
5. **Alpha Selection**: Make sure that alpha is dynamically updated, and reselected at every iteration.
