# Experiment 2

## Goal
Compare the VC repair algorithms as function of eps. 

## Datasets 
Use adult, census, compas and tax for experiments. 
Use adult100 for canary run. 

## Synthetic data generation 
Create synthetic data with size 5K, generated by models of MST and AIM with different eps. 
The models are already located in the models folder, so sample only. 
Use 5 different seeds for the sampling algorithm. 
The sweep is done here, as you choose different models to sample from. 
You can start the sweep from eps=0.3. 

## Marginals generation 
Select 20 marginals with privacy budget 0.5 for selection and 0.5 for generation. 

## Repairing
Use the 3 VC repairing algorithm. 
Make sure that: 
1. Vanilla VC takes the vertex with the maximal degree at each iteration. 
2. Classic selects an edge randomly and remove it. 
3. The weighted uses the dynamic alpha. 

## Running on remote
Before running the job on remote, run a canary run on adult100, just to check that all repair algorithms and all generation algorithm work properly. 
When pulling result back, make sure that it is done by zipping the csvs of each experiment and getting it locally. 
Make sure to give the processes enough memory to run and give them few hours timeout.
