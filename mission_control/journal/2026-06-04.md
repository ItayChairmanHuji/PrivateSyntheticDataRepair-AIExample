# Research Journal - 2026-06-04

## Status Update: Experiment 8 Fix
- **Issue**: Tax dataset was failing at 300K sample size due to a "Quadratic Trap" in the violation detection engine.
- **Root Cause**: `ValueGroupedEngine` performed a nested loop over all unique `(State, Salary, Rate)` groups. At 300K, this resulted in billions of iterations.
- **Optimization**: Implemented **Partitioned Value Grouping**. The engine now partitions data by equality predicates (e.g., `State`) before checking inequality predicates. This reduces the complexity from $O(U^2)$ to $O(P \times (U/P)^2)$ where $P$ is the number of partitions.
- **Validation**:

    - Implemented `GroupAwareGraph` in `s04_repairing`.
